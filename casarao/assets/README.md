# Assets — Casarão Assombrado

Convenção de nomes (o motor procura exatamente estes caminhos):

- `assets/npcs/<id>.png` — um por NPC
- `assets/salas/<id>.png` — um por sala

Os `<id>` são as chaves usadas no `casarao_mapa.json` (não os nomes bonitos).

## NPCs (8)
templario, madeirense, pirata, cavaleiro, enchilito, viking, rastafarian, gentleman

## Salas (16)
hall, salao, capela, quarto_infantil, lavandaria, arrecadacao,
corredor_principal, biblioteca, quarto_principal, escritorio, quarto_hospedes, corredor_antigo,
observatorio, janela, telhado, compartimento_secreto

Se uma imagem não existir, o motor mostra automaticamente um placeholder — podes testar o jogo antes de teres todas as imagens prontas.
